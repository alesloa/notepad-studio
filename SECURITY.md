# Security Policy

## Supported Versions

Notepad Studio is pre-1.0 (currently version `0.0.5`). Only the latest release on
the `main` branch is supported — security fixes land there. Older snapshots are
not maintained.

## Reporting a Vulnerability

**Please do not open a public issue for security problems.** Disclosing a
vulnerability publicly before a fix is available puts users at risk.

Instead, report it privately through GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** (Security Advisories).
3. Fill in the details of the issue.

This opens a private advisory visible only to the maintainers, so we can
investigate and prepare a fix before anything is made public.

Please allow a reasonable amount of time for the issue to be investigated and
fixed before any public disclosure. We'll keep you updated on progress and let
you know when a fix has shipped.
